# AI-focus Instagram carousel

Второй вариант витринной карусели с акцентом на:

- AI-генерацию изображения для каждого поста;
- выбор между AI-изображением и стоковым фото;
- собственные API-ключи и порядок AI-провайдеров;
- локальную OpenAI-compatible модель через публичный HTTPS gateway;
- автоматический fallback и контур публикации.

Формат слайдов: 1080 × 1350 px. Шестой кадр намеренно не содержит текста, логотипа или интерфейса — это чистый фон для самостоятельного добавления сайта и CTA.

Важно: прямые `localhost`, private IP и HTTP endpoint продукт блокирует. Для локальной модели нужен публичный HTTPS gateway.
