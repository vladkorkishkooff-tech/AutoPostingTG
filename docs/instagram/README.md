# Instagram showcase

Готовая карусель для витрины AutoPostingTG.

- Формат: 1080 × 1350 px (4:5), PNG.
- Слайды: AI-изображения, генератор, пакетный режим, очередь, автоматизации, Telegram bot → канал и чистый финальный фон.
- Данные в интерфейсах демонстрационные; функции соответствуют реализованному продукту.
- Исходник: `showcase.html`, переключение через `?slide=1` … `?slide=6`.

Актуальная редакция с изменёнными текстами экспортируется в `revised-final`: `01-cover.png` → `07-clean-background.png`.

Готовая подпись и alt-тексты находятся в `captions.md`.
