# Посты через AI-агента или бесплатную модель

AutoPostingTG принимает не только ответы платных API. Любой агент, ChatGPT/Claude с бесплатным лимитом, Copilot, Gemini, Ollama или другая модель может подготовить один стандартный JSON-пакет, а Mini App проверит его и добавит посты в Queue.

## Быстрый сценарий

1. Откройте в Mini App раздел **Ещё → Актуальные идеи**. Он получает темы из Google News RSS и показывает только материалы не старше 7 дней.
2. Откройте ссылку источника, убедитесь, что факт подтверждён, и передайте агенту тему вместе с источниками.
3. Вставьте промпт ниже. Попросите модель вернуть **только JSON**, без Markdown-блока и пояснений.
4. Скопируйте JSON в **Ещё → Импорт от AI-агента**, выберите канал и нажмите «Проверить и добавить в очередь».
5. В Queue отредактируйте и подтвердите посты. Импорт никогда не публикует их сам.

## Готовая инструкция для модели

```text
Ты — редактор научно-популярного Telegram-канала. Подготовь 1–5 постов на русском языке по теме: {{TOPIC}}.

Правила исследования:
- Используй только факты, которые можно подтвердить указанными HTTPS-источниками.
- Не выдумывай цифры, цитаты, даты и результаты экспериментов.
- Сначала проверь актуальность источников. Укажи текущие дату и время в ISO-8601 в research.asOf.
- Для каждого источника укажи title, url и, если доступно, publishedAt.
- Если факт не подтверждается, напиши об ограничении или не включай его.

Правила текста:
- Один пост — одна ясная мысль; русский язык, без Markdown и служебных комментариев.
- mode должен быть одним из: normal, short, long, funny, wow, strict.
- Добавь image.prompt — конкретное описание изображения без текста и логотипов; image.url оставь пустым, если готовой картинки нет.

Верни только валидный JSON по схеме autopostingtg.post-pack.v1:
{
  "schemaVersion":"autopostingtg.post-pack.v1",
  "generatedAt":"<ISO-8601>",
  "sourceMode":"free-model",
  "research":{"topic":"<тема>","asOf":"<ISO-8601>","sources":[{"title":"<название>","url":"https://...","publishedAt":"<ISO-8601>"}]},
  "posts":[{"id":"post-1","topic":"<тема>","mode":"wow","text":"<готовый текст>","image":{"prompt":"<визуальный промпт>","source":"agent"}}]
}
```

## Полностью бесплатный и локальный вариант

Запустите Ollama/LM Studio или другого локального агента, дайте ему этот промпт и сохраните JSON-файл. Затем импортируйте файл вручную через Mini App — API-ключ не нужен. Для генерации изображений можно использовать локальный image-модельный инструмент и добавить публичный `image.url` или оставить `image.prompt`, чтобы подобрать картинку позже.

Локальный LLM можно также подключить как пользовательский OpenAI-compatible provider, но сервер принимает только публичный HTTPS Base URL. `localhost`, приватные IP и HTTP намеренно блокируются: это защита от SSRF. Для домашней модели нужен безопасный HTTPS-шлюз (например, собственный reverse proxy с авторизацией).

## Контракт для разработчика

- JSON Schema: [`post-pack.schema.json`](./post-pack.schema.json)
- API: `POST /api/content/import` с `{ "channelId": 123, "pack": <json> }`
- За один импорт принимается 1–5 постов.
- Обязательны `research.asOf` и хотя бы один HTTPS-источник.
- В базу сохраняется provenance в `posts.source_meta`, поэтому можно объяснить, откуда взялся пост.
- Даты источников помогают отбрасывать устаревшие идеи, но финальная проверка владельца остаётся обязательной.
