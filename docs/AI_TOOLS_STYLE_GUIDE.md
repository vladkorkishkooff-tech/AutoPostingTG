# Стандарт стиля: Канал «AI-инструменты» (@AI_toolsSsS)

Этот документ фиксирует редстандарт, правила фильтрации и эталонные примеры для Telegram-канала **[AI-инструменты](https://t.me/AI_toolsSsS)** (`@AI_toolsSsS`).

---

## 1. Концепция и железный фильтр качества

- **Позиционирование:** *«Нейросети для работы, бизнеса и жизни. Инструменты, инструкции, промпты и реальные сценарии — без воды. Ведёт Влад, fullstack-разработчик.»*
- **Аудитория:** Fullstack-разработчики, бэкендеры, архитекторы, автоматизаторы и практики.
- **Главный фильтр (Zero Hype):** **Категорически запрещены поверхностные «обёртки» (wrappers), игрушки на один вечер и маркетинговые пузыри.**
- **Критерий отбора:** Инструмент должен решать **реальную инженерную боль** разработчика (парсинг документов, транскрибация без зависимостей, структурированный вывод, локальный инференс, нормализация API, ускорение пайплайнов).

---

## 2. Структура эталонного поста

Каждый пост лаконичен (чтение до 20 секунд) и следует формуле:

1. 🛠️ **Название инструмента — [Суть и назначение в 1 строку простым языком]**
2. **Какую боль решает (1–2 коротких предложения):** Конкретная проблема существующих решений (тяжелые зависимости, закрытые API, зоопарк форматов).
3. **💡 Киллер-фича:** Техническое преимущество (чистый C/C++, работа без PyTorch/CUDA, экономия памяти, работа оффлайн).
4. **🏷 Условия и старт в 1 строку:** Open Source / лицензия + CLI-команда или пример кода.

---

## 3. Эталонный опубликованный пост (Golden Benchmark)

👉 **[Пост #14 в канале @AI_toolsSsS](https://t.me/AI_toolsSsS/14)**:

> 🛠️ **Microsoft MarkItDown — утилита, которая превращает любой файл в чистый Markdown для нейросетей**
> 
> Главная боль любого RAG или агента — зоопарк форматов: PDF, Word, Excel-таблицы и презентации. Обычно под каждый формат приходится городить отдельный парсер или платить за облачный OCR.
> 
> Инженеры Microsoft выкатили опенсорсную утилиту, которая перегоняет PDF, DOCX, XLSX, PPTX, HTML и даже аудио в идеально структурированный Markdown без лишнего визуального мусора.
> 
> 💡 **Киллер-фича:** работает полностью локально без облачных API и экономно сохраняет структуру таблиц для контекста LLM.
> 
> 🏷 **Старт в терминале:**  
> `pip install markitdown`  
> `markitdown file.pdf > file.md`

## 4. Пул проверенных инженерных инструментов (уровня MarkItDown)

Только инструменты с реальным инженерным весом:

1. **Microsoft MarkItDown** — конвертер любого документа (PDF, Excel, PPTX, аудио) в чистый Markdown без облаков.
2. **LiteLLM** — I/O прокси, объединяющий 100+ LLM (OpenAI, Anthropic, Bedrock, Ollama, DeepSeek) под единым интерфейсом с балансировкой и фолбэками.
3. **whisper.cpp** — чистая C/C++ реализация Whisper от Георгия Герганова: транскрибация без Python и PyTorch, летает на CPU и Apple Silicon.
4. **Instructor (jxnl)** — строгий валидированный вывод из LLM через Pydantic-схемы с автоматическими ретраями при ошибках парсинга.
5. **vLLM (PagedAttention)** — стандарт быстрого продакшн-сервинга открытых моделей с динамическим управлением KV-кэшем.
6. **llama.cpp** — фундамент локального инференса: запуск квантованных GGUF-моделей на обычном железе без CUDA-ада.
7. **FastEmbed (Qdrant)** — генерация векторных эмбеддингов в Python через легковесный ONNX Runtime без гигабайтных зависимостей PyTorch.
8. **SQLGlot** — опенсорсный парсер и транспайлер SQL между 20+ диалектами, незаменимый для надежных Text-to-SQL агентов.
9. **uv (Astral)** — сверхбыстрый пакетный менеджер для Python на Rust, ускоряющий сборку окружений в 10–100 раз.
10. **Mem0** — локальный слой долговременной памяти для агентов с интеллектуальной дедупликацией фактов.
